# BlazeScript

BlazeScript is a statically typed, compiled programming language designed to target WebAssembly using an LLVM backend and a handwritten frontend.

## Prerequisites

Before building the project, ensure you have the following installed on your system:
* **LLVM 22** (Required for the backend code generation)
* **CMake** (v3.20 or higher)
* A **C++17** compatible compiler (GCC, Clang, or Apple Clang)

## Building

Clone the repository and build using CMake:

```bash
git clone https://github.com/kashyap404/BlazeScript.git
cd BlazeScript
cmake -S . -B build
cmake --build build
```

The compiler executable is generated at:

```bash
./build/blazescript
```

## Usage

```bash
./build/blazescript [options] <file>
```

If no flags are provided, the compiler runs semantic analysis by default.

### Command-Line Flags

| Flag               | Description                                               |
| :----------------- | :-------------------------------------------------------- |
| `-t`, `--tokens`   | Print tokens generated by the scanner.                    |
| `-ast`, `--ast`    | Print the Abstract Syntax Tree.                           |
| `-s`, `--semantic` | Run semantic analysis for type and scope checking.        |
| `-ir`, `--ir`      | Generate LLVM IR.                                         |
| `-o <file>`        | Write LLVM IR to the specified file when used with `-ir`. |
| `-h`, `--help`     | Show the usage menu.                                      |

### Examples

Run semantic analysis:

```bash
./build/blazescript tests/test_semantic.blz -s
```

Print the AST:

```bash
./build/blazescript tests/test_semantic.blz -ast
```

Generate LLVM IR:

```bash
./build/blazescript tests/test_ir.blz -ir
```

Write LLVM IR to a `.ll` file:

```bash
./build/blazescript tests/test_ir.blz -ir -o test.ll
```

## Syntax Example

```blz
fn main() -> i32 {
    let x: i32 = 10;
    let y: i32 = 20;
    let is_valid: bool = true;

    if (is_valid and x < y) {
        return x + y;
    }

    return 0;
}
```
