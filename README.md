# BlazeScript

BlazeScript is a statically typed, compiled programming language designed to target WebAssembly using LLVM backend and a handwritten frontend
## Building

Clone the repository and build the compiler using Make.

```bash
git clone https://github.com/kashyap404/BlazeScript.git
cd BlazeScript
make
```

## Usage

Run the compiler by passing the source file path. You can optionally provide flags to inspect specific compiler stages. If no flags are provided, the compiler defaults to running semantic analysis.

```bash
./blazescript [options] <file>
```

### Command-Line Flags

| Short Flag | Long Flag | Description |
| :--- | :--- | :--- |
| `-t` | `--tokens` | Print the list of tokens generated by the scanner. |
| `-ast` | `--ast` | Print the Abstract Syntax Tree (AST) representation. |
| `-s` | `--semantic` | Run the semantic analyzer for type and scope checking. |
| `-h` | `--help` | Show the usage menu and exit. |

### Examples

Print the token stream:

```bash
./blazescript tests/test_semantic.blz -t
```

Print the AST and run semantic analysis:

```bash
./blazescript tests/test_semantic.blz -ast -s
```

## Syntax Example

```blz
fn main() -> i32 {
    let x: i32 = 10;
    let y: i32 = 20;
    let is_valid: bool = true;

    if (is_valid and x < y) {
        return x + y;
    }

    return 0;
}
```
