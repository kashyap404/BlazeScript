# BlazeScript

BlazeScript is a statically typed, compiled programming language with a handwritten frontend and an LLVM-based backend. The compiler translates BlazeScript source code into LLVM IR.

## Features

BlazeScript currently supports:

* **Lexical analysis** using a handwritten scanner
* **Parsing** and Abstract Syntax Tree (AST) generation
* **Static type checking**
* **Scope and symbol checking**
* **Variable declarations** using `let`
* **Explicit type annotations**
* **Functions** with typed parameters and return types
* **Function calls**
* **Assignments**
* **Control flow**

  * `if` / `else`
  * `while`
* **Return statements**
* **Arithmetic operators**

  * `+`
  * `-`
  * `*`
  * `/`
* **Comparison operators**

  * `==`
  * `!=`
  * `<`
  * `<=`
  * `>`
  * `>=`
* **Boolean operators**

  * `and`
  * `or`
* **Unary operators**

  * `-`
  * `!`
* **LLVM IR generation**

### Currently Supported Types

* `i32`
* `bool`

## Prerequisites

Before building the project, ensure you have the following installed on your system:

* **LLVM 22** (required for backend code generation)
* **CMake** (v3.20 or higher)
* A **C++17-compatible compiler** (GCC, Clang, or Apple Clang)

## Building

Clone the repository and build using CMake:

```bash
git clone https://github.com/kashyap404/BlazeScript.git
cd BlazeScript
cmake -S . -B build
cmake --build build
```

The compiler executable is generated at:

```bash
./build/blazescript
```

## Usage

```bash
./build/blazescript [options] <file>
```

If no compilation-stage flag is provided, the compiler runs semantic analysis by default.

### Command-Line Flags

| Flag               | Description                                               |
| ------------------ | --------------------------------------------------------- |
| `-t`, `--tokens`   | Print tokens generated by the scanner.                    |
| `-ast`, `--ast`    | Print the Abstract Syntax Tree.                           |
| `-s`, `--semantic` | Run semantic analysis for type and scope checking.        |
| `-ir`, `--ir`      | Generate LLVM IR.                                         |
| `-o <file>`        | Write LLVM IR to the specified file when used with `-ir`. |
| `-h`, `--help`     | Show the usage menu.                                      |

## Syntax Example

```blz
fn main() -> i32 {
    let x: i32 = 10;
    let y: i32 = 20;
    let is_valid: bool = true;

    if (is_valid and x < y) {
        return x + y;
    }

    return 0;
}
```

```text
Semantic Analysis

        |

    LLVM IR
```
